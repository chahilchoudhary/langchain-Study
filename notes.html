📌 What is LangChain?

LangChain is an open-source framework for building apps powered by LLMs (GPT, Claude, etc.). It connects the LLM with your data, tools, and memory, and lets you chain steps together.

🧠 LLM = the brain, LangChain = the body, hands, and memory around it.

✅ Benefits

  • 🔄 Model-agnostic: swap models with minimal code change
  • 🧩 Modular: reusable pieces
  • 🔗 Chaining: prompt → model → parser
  • 📚 RAG support: use your own documents
  • 🛠️ Agents and tools: LLM calls APIs/functions
  • 💾 Memory: keeps conversation context
  • 🔌 Many integrations: vector DBs, loaders, APIs
  • 👥 Big community: docs and examples

🧱 Components of LangChain

1🤖 Models

  • Language model: text in, text out
  • Embedding model: text to vectors, so meaning can be searched

2📝 Prompts

Reusable templates for the model input, with variables filled at runtime.

3⛓️ Chains

Steps linked together; one output feeds the next.

Prompt→Model→Parser

4📂 Indexes

  • Document loader: PDFs, web, files, DBs
  • Text splitter: big docs into chunks
  • Vector store: stores embeddings (FAISS, Chroma, Pinecone)
  • Retriever: fetches relevant chunks

5💾 Memory

Stores earlier messages so the model remembers the conversation.

6🕵️ Agents

The LLM decides which tools to use (search, calculator, APIs) and in what order.

⚔️ LangChain vs LlamaIndex vs Haystack

LangChainLlamaIndexHaystack
Main focusGeneral LLM apps, chains, agentsData indexing and retrieval (RAG)Search and RAG pipelines
Best forComplex workflows, agents, tool useQ&A over your documentsProduction search/QA systems
StrengthFlexibility, huge ecosystemEasy, strong data connectorsClean pipelines, production-ready
WeaknessCan feel complex/abstractLess suited for agent-heavy appsSmaller community
Quick rule
  • Need agents and flexible workflows → LangChain
  • Need to chat with your data → LlamaIndex
  • Need production search pipelines → Haystack
